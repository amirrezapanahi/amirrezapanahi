## 👨‍💻 About Me

I'm a **Full-Stack Software Developer** interested in building reliable systems that connect **software, hardware, and real-world automation**.

My work spans frontend interfaces, backend services, APIs, databases, automation tools, robotics, IoT systems, and microcontroller-based projects.

I'm especially interested in projects where **software interacts with physical systems**, sensors, actuators, devices, and intelligent automation.

I care about:

* Clean and maintainable code
* Full-stack application architecture
* Backend and API design
* Hardware-software integration
* Robotics and embedded systems
* Practical automation
* Thoughtful user experience
* Continuous learning and improvement

## 🧠 Engineering Philosophy

> Build systems that are simple to understand, reliable in practice,
> and useful in the real world.

I prefer **simple architecture over unnecessary complexity**,
**maintainability over cleverness**, and **working products over unfinished ideas**.

My goal is not only to write software, but to understand how the entire system works —
from the **user interface and backend** all the way down to **hardware and physical devices**.
